### HTML Assignment 

### ✨ Overview

This project is a simple static website built using **HTML** and **CSS**, based on the provided layout plans as a part of course studies of Full Stack Web Development (TX00FT04-3002).  
The website includes three pages:
- **Home**
- **Products**
- **Contact**

The goal of this assignment is to practice creating a structured website with multiple pages, apply custom styling, and integrate images, colors, and fonts.
